# Mini Shopping Cart

A simple Mini Shopping Cart project built using HTML, CSS, and JavaScript.

## Features

* 6 different products
* Product image, name, and price
* Add products to cart
* Same product increases its quantity instead of being added again
* Cart item count
* Increase and decrease product quantity
* Remove products from cart
* Automatic total price calculation
* Empty cart message
* Responsive design for mobile screens
* Hover and click effects on buttons and product cards

## Technologies Used

* HTML
* CSS
* JavaScript

## How It Works

Products are stored in a JavaScript array of objects. Users can add products to the cart, change their quantities, remove products, and view the automatically updated total price.
